Фронтенд и продуктовые сайты: от одностраничных лендингов до scroll-driven
презентаций на WebGL. Делаю сайты, которые продают, и довожу их до состояния,
когда за интерфейс не стыдно.

**Стек:** TypeScript · Next.js (App Router) · React · Tailwind CSS · Three.js / R3F ·
GSAP + Lenis · Motion · Python · Unity (C#)

### Избранные работы

**NOVA//AER** — концепт-сайт deep-tech компании
Десять scroll-сцен на одном WebGL-канвасе и две интерактивные демо: 3D-модель сети
и симулятор воздушного трафика.
[Открыть сайт](https://novaaer.vercel.app) · [Код](https://github.com/mauvaislab/novaaer)
`Next.js` `React Three Fiber` `GSAP` `Lenis`

**mauvaislab** — сайт студии веб-разработки
Собственный сайт услуг. Задача была прямая: сайт должен сам быть главным
аргументом в разговоре с клиентом.
[Открыть сайт](https://mauvaislab.vercel.app) · [Код](https://github.com/mauvaislab/mauvaislab-site)
`Next.js` `Three.js` `Motion` `Tailwind`

**VOREX** — презентационный сайт майнинг-проекта
Scroll-driven повествование о цикле «добыл → пересёк порог → артефакт в кошельке»
и о Telegram-боте, который его ведёт.
[Открыть сайт](https://vorex-pi.vercel.app)
`Next.js` `WebGL` `TypeScript`

**УГОЛЁК** — заказ в кафе по QR-коду
Прототип платформы: гость сканирует код на столике и заказывает с телефона,
кухня и официант видят заказ у себя. Два интерфейса на одной демо-странице.
[Открыть прототип](https://cafelab-silk.vercel.app)
`HTML` `JavaScript` `Supabase`

**WinPoint** — лендинг удалённого отдела продаж, Алматы
Менеджеры, РОП, CRM, гарантия KPI. Одностраничник с формой и приёмом заявок
в таблицу.
`HTML` `Tailwind CSS` `Google Apps Script`

**Locostep** — беговая дорожка для VR
Скорость снимается с Arduino и уходит по UDP прямо в Unity-приложение на планшете.
`Unity` `C#` `Arduino` `UDP`
