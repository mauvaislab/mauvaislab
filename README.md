## Автоматизация и интеграции

**Автоматизации на n8n** — обработка обращений и догрев сделок
Четыре рабочих сценария для сети семейных развлекательных центров: маршрутизация
комментариев в Instagram и Threads с определением тональности через GPT, очередь
доставки с повторными попытками и статусами, поиск замолчавших клиентов и
автоматический перевод сделки по стадиям Битрикса.
[Код и разбор кейсов](https://github.com/mauvaislab/n8n-automations)
`n8n` `MySQL` `Битрикс24 REST` `OpenAI`

**Locostep** — беговая дорожка и виртуальная локация
Реальная скорость человека снимается с Arduino, уходит по UDP в Unity, и персонаж
на экране идёт с той же скоростью. Отдельный экран оператора для управления
сеансом.
[Код](https://github.com/mauvaislab/locostep-scripts)
`Unity` `C#` `UDP` `Arduino`
